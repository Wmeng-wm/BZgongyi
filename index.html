          上轴·D连接皮带中轴·B+C同轴下轴·A主动
        

      

      

        
齿轮比公式：PPI ∝ (B×D) / (A×C)

        

          🔺 增加密度（PPI↑）：减小 A 和 C 齿，增大 B 齿

          🔻 减少密度（PPI↓）：增大 A 和 C 齿，减小 B 齿

          ⚙ D 齿固定 46 齿，一般不换
        

        
操作步骤：

          ① 输入目标 PPI 或节距 → ② 查看推荐齿轮组合 → ③ 选择偏差最小的组合 → ④ 停机更换 A/B/C 齿轮 → ⑤ 试运行确认密度

        
⚠ 注意：换齿轮前必须停机断电，安装后试运行检查咬合和编织效果。
