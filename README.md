# BZgongyi

医疗编织、缆绳、绕丝工艺计算器。

## 功能

- 编织计算：PPI、节距、编织角度、用丝比、单股用丝和机台总用丝。
- 绕丝计算：7x7 缆绳、单层绕丝、双层绕丝、三层绕丝、密绕捻距、外径反推。
- 单锭机计算：宽度、旦尼尔、节距互算。
- 克重转换：金属丝和纤维丝重量、长度、单股长度换算。

## 文件

- `index.html`：平台入口。
- `braid.html`：编织工艺计算。
- `coil.html`：缆绳和绕丝工艺计算。
- `single.html`：单锭机计算。
- `weight.html`：丝材克重和长度转换。
- `calculator-tests.html`：核心公式浏览器测试页。

## 主要改进点

- 补齐 `coil.html` 中原本只弹窗提示的双层绕丝、三层绕丝、外径反推和历史记录功能。
- 增加输入校验，避免 0、负数、空值导致静默错误结果。
- 统一绕丝页面的输出文本，复制、保存历史和导出 TXT 使用同一份结果。
- 校准参数支持保存、导出、导入和恢复默认。
- 新增轻量测试页，便于修改公式后快速检查核心计算是否仍然正常。
- 入口页移除 iframe，改为直接打开各工具页面，移动端高度、浏览器返回和分享链接更稳定。

## 单位约定

- 直径、芯径、丝径、节距使用 `mm`。
- 成品长度和用丝结果使用 `m`。
- 损耗预留以百分比输入，并已计入“含损耗”结果。
- 外径反推是工艺起点估算，实际量产参数建议结合设备张力和实测外径校准。

## 使用建议

1. 先按默认参数计算一遍，确认页面正常。
2. 根据设备和材料实测结果调整“校准设置”。
3. 将校准参数导出备份，换浏览器或换电脑后可导入。
4. 修改公式后打开 `calculator-tests.html`，确认测试全部通过。

## 说明

该工具用于医疗编织和绕丝工艺参数辅助计算。结果应结合实际设备张力、材料批次、热处理/定型工艺和质检数据进行校准。
