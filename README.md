# BZgongyi

医疗编织、缝合线、绕丝工艺计算平台，单文件 SPA，部署于 Cloudflare Workers。

## 功能

- 编织计算：PPI、节距、编织角联动，输出用丝比、单目长度、单股/机台用丝、覆盖率、当前孔径、输出外径。
- 绕丝/缆绳：7x7 缆绳、单/双/三层绕丝，密绕/间隙/角度互算、外径反推丝径，校准参数与历史记录保存在浏览器。
- 缝合线：单锭机 W/D/P 互算；双锭机按线号、锭数、PPI、目标外径反推 D 数；D/dtex/Tex 互转。
- 克重转换：金属丝/纤维丝重量长度换算、强度换算、克重转张力。
- 齿轮反查：按 A/B/C/D 齿轮组合匹配目标 PPI/节距，附调整教程与变频器参数参考。
- 产线校准：分丝机倍率重算、移动量校准。

## 双锭机校准

- UHMWPE：按实测参考行（`DUAL_DATA`）推荐 D 数，暂不走目标外径反推。
- LCP 及其他材料：按目标外径 + 锭数 + PPI + 材料密度反推 D 数。
- LCP 三点实测校准：UHMWPE 110D/8锭/30PPI→0.465mm，LCP 200D/8锭/10PPI→0.60mm，LCP 200D/8锭/30PPI→0.55mm；锭数按 √N 外推。
- 外径预估为工艺起点估算，量产参数建议结合设备张力、材料批次、热处理/定型工艺和质检数据实测校准。

## 编织覆盖率、当前孔径与输出外径

- **口径**：覆盖率 = 芯棒表面被纱线盖住的面积占比；**100% 就是网孔闭合、看不见芯棒**，此时孔径为 0。
- 单向覆盖率：`C1 = (锭数/2) × 丝宽 w ÷ (π × 芯棒直径 D × cosθ)`，θ 为单股螺旋角（与轴线夹角，页面「编织夹角」= 2θ）。
  几何含义：单侧每根纱线在垂直于轴线的截面上占 `w/cosθ` 弧长（面积法与截面法推导一致）。
- 双方向交织覆盖率：`C = 1 − (1 − C1)²`，`C1 ≥ 1` 时按 100% 封顶。
- **当前孔径**（页面 KPI）：把芯棒表面展开成平面、两个方向的纱带（宽 w）交叉，孔是菱形——
  - 孔径 `g = w × (1/C1 − 1)` = 同向相邻纱线的净间隙 = 菱形孔内切圆直径 = 能漏出芯棒的最大尺寸
  - 菱形孔两条对角线：轴向长 `= g ÷ sinθ`，周向宽 `= g ÷ cosθ`（需要时按此换算式与实测对照）
  - 自洽校验：孔心格基元面积 `p²/sin2θ`（p = 同向纱线中心距），每格恰 1 孔 → 孔面积占比 `= (g/p)² = (1−C1)² = 1 − C`
  - 即 `g = 0 ⇔ C = 100%`，两者永远同步（回归测试已断言）
- 丝宽 `w` 为纱线压扁后宽度：圆丝/单丝 ≈ 丝径，复丝、扁丝按实测或 丝径 × 1.5~2.5 填写；页面默认随「丝径」自动同步，手动改过后不再覆盖。
- 输出外径：`OD = 芯棒 D + 2 × 丝径 d`（单侧一层丝厚，不含额外增厚系数）。
- 以上均为工艺起点估算，纱线压扁/张力/定型会改变实际孔径，量产前请用实测（投影仪/显微镜测孔径）校准 `w`。

## 本地测试

```bash
python -m http.server 8765        # 打开 http://127.0.0.1:8765/
node tests/braid.test.mjs         # 编织页公式回归测试（无第三方依赖）
```

## 文件

- `index.html`：平台入口，全部功能位于单文件。
- `build.py`：将 `index.html` 内嵌生成 `src/worker.js`。
- `tests/braid.test.mjs`：编织页本地回归测试（Node，无需 npm 依赖）。
- `src/worker.js`：Cloudflare Worker 源码，自动生成，勿手改。
- `wrangler.toml`：部署配置，域名 `bzgongyi.ksjizhang.top`。
- `README.md`：项目说明。

## 构建与部署

```bash
python build.py
npx wrangler deploy
```

## 单位约定

- 直径、芯径、丝径、节距使用 `mm`；成品长度和用丝结果使用 `m`。
- 损耗预留以百分比输入，并已计入“含损耗”结果。

## 说明

该工具用于医疗编织、缝合线和绕丝工艺参数辅助计算。所有公式结果应结合实际设备和实测数据进行校准。
